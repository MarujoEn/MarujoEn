## Featured Projects & Code Studies

Here are the main architecture, logic, and automation projects I have developed independently and during my technical studies:

### [PHP Pokémon Battle Simulator](https://github.com/MarujoEn/php_pokebattle_study)
* **Description:** A functional Pokémon battle simulator built to run directly in the terminal (CLI) without using external frameworks.
* **Key Learnings:** Practical consolidation of the **MVC (Model-View-Controller)** architectural pattern, data isolation and cross-referencing via **JSON** files, in-memory state management to protect source data, and development of a simple turn-based artificial intelligence.

### [ASCII Wave Simulator (C#)](https://github.com/MarujoEn/ascii-wave)
* **Description:** A highly performant 2D fluid simulator rendered directly in the terminal using ANSI Escape Codes (TrueColor 24-bit).
* **Key Learnings:** Overlapping sine wave physics in real-time, optimized rendering using **Double-buffering (`StringBuilder`)** to prevent screen tearing, and support for CLI color palette automation integration (`pywal`).

### [PHP Full-Stack Study Calculator](https://github.com/MarujoEn/php_study_calculator)
* **Description:** A monolithic web application built to validate data persistence flows and secure operations with relational databases.
* **Key Learnings:** Full integration between PHP and **PostgreSQL** using **PDO (PHP Data Objects)**, vulnerability mitigation against **SQL Injection** via prepared statements, infrastructure exception handling, and native relational schema modeling.

### [Task Manager CLI (C# & SQLite)](https://github.com/MarujoEn/GerenciadorTarefas-SQLite)
* **Description:** A robust C# console application focused on data lifecycle management (Full CRUD).
* **Key Learnings:** Practical transition from volatile in-memory storage to real disk persistence using **SQLite / Microsoft.Data.Sqlite**, transaction control with `ExecuteNonQuery`, and workflow management with precise error handling (`try-catch`).
